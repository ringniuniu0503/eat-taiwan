# Eat Taiwan 吃台灣

A local friend's guide to 36 Taiwanese foods for first-time visitors, in English, 繁體中文, 한국어 and 日本語.

- `index.html`: the page (layout, styles, scripts)
- `foods.js`: all food content, translations and UI text
- `img/`: food illustrations (made with AI image tools)

Static site, no build step. Deployed with Netlify from the `main` branch.
